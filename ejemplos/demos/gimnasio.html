Reserva online · opcional

Reservá y pagá online, con confirmación verificada.

Si Base Activa activa este módulo, el turno se confirma solo cuando el pago está verificado. Mientras tanto, los turnos se coordinan por WhatsApp.

  1. Elegís día y horario.
  2. Pagás en el checkout del proveedor de pagos, fuera de esta web.
  3. El sistema verifica el pago.
  4. Se confirma el turno y el local recibe el aviso por email.

Demo: se activa con la cuenta de cobro del negocio, un servidor y un proveedor de email. Ver cómo funciona ↗

Preguntas frecuentes

Antes de escribirnos.

¿Puedo probar antes de inscribirme?

Consultá por una clase de prueba. Si el gimnasio la ofrece, se coordina por mensaje o con la reserva online cuando esté activa.

¿Piden apto físico?

Los requisitos de ingreso los define el gimnasio y se informan al inscribirte. Esta página no reemplaza una evaluación médica.

¿Cómo se paga el plan?

Medios de pago, renovación y condiciones se informan al inscribirte. Esta web no cobra cuotas.
