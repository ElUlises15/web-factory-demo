# Web Factory · demo de la landing

Build estático de **demostración** de la landing de Web Factory, generado a partir del repositorio privado
`web-factory` (rama `front/mejoras-v1`) con `tools/build_landing.py` (build no estricto).

- Publicado en GitHub Pages: https://elulises15.github.io/web-factory-demo/
- Es una demo: los canales de contacto todavía no están configurados y el sitio no se indexa
  (`noindex` en las páginas y `robots.txt` con `Disallow: /`).
- Los diseños de `ejemplos/` usan **negocios ficticios**; no son clientes reales.

Este repositorio contiene solo el resultado del build. No editar a mano: los cambios se hacen en el repo
fuente y se vuelve a generar.
